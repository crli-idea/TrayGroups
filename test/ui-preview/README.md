# 分组面板交互设计

从项目根目录打开 `./test/ui-preview/index.html`，或直接双击该 HTML。无需启动服务、安装依赖或联网加载素材。

预览针对点击 T 后的分组面板，提供顶部标签、侧边导航、折叠列表和紧凑面板四种布局。支持切换浅色/深色/系统主题、配色、面板宽度、圆角、图标大小、列数、标签字号与间距，也可修改分组名称、调整顺序和开关截图区。

左键、双击、右键菜单和截图仅为示例反馈，不调用真实程序，不截取屏幕。示例图标由内嵌 SVG 绘制。右键恢复或恢复全部会暂时移除示例图标，刷新页面或恢复默认设计即可还原。

外观修改尝试保存在浏览器本地存储中。点击“复制方案”可发回具体参数；点击“导出 HTML”可保存包含当前设计的独立文件，再次打开后仍可继续修改。浏览器禁止本地存储时优先使用导出功能。

工具选择：Figma 或 Penpot 适合设计布局与原型；VS Code 适合直接编写这个 HTML；ResEdit 或 Visual Studio 资源编辑器适合实现当前程序的 Win32 对话框。此文件是设计预览，确认方案后再将外观落实到原生程序，不需要把浏览器嵌入常驻进程。
